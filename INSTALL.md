# 🚀 Install — Cinematic GitHub Profile README

## 1. Open your profile repository

Open:

`https://github.com/priyanshu18611/priyanshu18611`

GitHub displays a profile README when a public repository has the same name as your username and contains `README.md`.

## 2. Replace README.md

Open `README.md` → Edit → delete old content → paste the included `README.md`.

## 3. Commit

Commit directly to the default branch.

## 4. Refresh your profile

Open:

`https://github.com/priyanshu18611`

The new cinematic profile README should appear at the top.

## Optional: Dynamic contribution snake

The README references the common Platane Snake generated SVG endpoint. For a more reliable setup, add the GitHub Action workflow from the official Platane/snk repository to your profile repository so the snake asset is generated by your own GitHub Actions workflow.
